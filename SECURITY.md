# Security

Isolinear opens files from anywhere, so a file that makes it crash, hang, use unbounded memory, run
code, write outside the file being saved, or reach the network is a security bug.

Please report it privately through GitHub's
[private vulnerability reporting](https://github.com/mlaib/isolinear/security/advisories/new), with
the file (or a way to make one) and what happened. Do not open a public issue first.

You can expect a first answer within a week. Fixes are released as soon as they are ready, and the
report is credited unless you prefer otherwise.
